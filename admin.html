Unggah file Excel

File dibaca langsung di browser Anda dan tidak dikirim ke mana pun. Pastikan di dalamnya ada sheet Data Form, Master Toko, Kamus Kode, dan Panduan.

Tambah pengguna

Ketik NIK: nama lengkap dan jabatan terbaca otomatis dari sheet Karyawan Aktif. Berikan NIK dan password awal ke yang bersangkutan. Begitu ditambahkan, akun langsung aktif dan bisa dipakai login, selama repository dan token GitHub sudah terisi di menu Publikasi.

Daftar pengguna

Hanya NIK di daftar ini, yang berstatus karyawan aktif dan punya password, yang bisa login. Ubah password langsung di kolomnya (otomatis disimpan saat Anda selesai mengetik), atau klik Reset password untuk membuat password acak baru. Karyawan yang berhenti cukup dinonaktifkan di Excel lalu Publikasi.

Permintaan reset password dari pengguna

Pengguna yang lupa atau ingin mengganti password memakai tab Reset password di halaman login, memilih password barunya sendiri, lalu mengirim kode (diawali SWAC2.) kepada Anda. Tempel kode di sini, periksa identitasnya, lalu klik Konfirmasi reset. Akunnya langsung aktif dengan password baru pilihan pengguna, dan Anda tidak pernah melihat passwordnya.
🔐 Catatan keamanan: password tersimpan di browser admin (dan cadangan terenkripsi), jadi jangan bagikan akses ke halaman admin ini. Ganti password pengguna yang bocor dengan Reset password.

Publikasi ke GitHub

Daftar periksa
    Token hanya disimpan sementara di tab ini dan dikirim langsung ke api.github.com. Token yang sama juga dipakai sebagai kunci cadangan terenkripsi (data/admin.bin), jadi di komputer lain Anda bisa klik Pulihkan dari GitHub dengan token itu. Tombol “Paket uji offline” menghasilkan offline.js supaya login bisa dicoba tanpa internet dan tanpa token.
